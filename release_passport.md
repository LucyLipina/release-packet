# Паспорт выпуска 1.5.0-rc1 (DOC-17)

## 1. Общие сведения
| Параметр | Значение |
|---|---|
| Версия | 1.5.0-rc1 |
| Цель | Внедрение функционала заявок с миграцией схемы S1 → S2 |
| Спецификация | SPEC-1.0 |
| Исходный код | `DEMO-COMMIT-015-NOT-A-REAL-GIT-ID` (учебный маркер) |
| Пакет | `app-1.5.0-rc1.zip` - Целостность не подтверждена, хеш отсутствует |
| Дата | В пакете отсутствует |
| Статус готовности | **НЕ ГОТОВ (Blocked)** — есть непройденные обязательные проверки |

## 2. Среда и зависимости
- ОС: Linux x64.
- Python: 3.11 или 3.12.
- PostgreSQL: 15 или 16.
- Свободное место: минимум 2048 МиБ.

## 3. Параметры конфигурации (без секретов)
| Имя | Значение в пакете | Назначение |
|---|---|---|
| `APP_PORT` | 8081 | Порт приложения |
| `DB_HOST` | `lab-db-01` | Хост БД |
| `DB_NAME` | `service_lab` | Имя БД |
| `ATTACHMENTS_DIR`| `/srv/service_lab/attachments` | Директория вложений |
| `max_attachments`| 3 | Лимит файлов (соответствует SPEC) |

Секреты передаются отдельным механизмом, в паспорт не включаются.

## 4. Миграция и восстановление
- **Миграция:** M015 (расширяющая, добавляет необязательную категорию).
- **Схемы:** S1 (до) → S2 (после).
- **Возврат:** до 8 минут (до открытия записи). После включения `category_required` и появления новых записей возврат требует преобразования данных.
- **Бэкап:** B-1755 (БД, вложения, конфиг).
- **Тест восстановления:** `last_restore_test` отсутствует в пакете.

## 5. Известные ограничения и блокеры
1. **R_RESTORE (blocked):** нет стенда для восстановления (`restore-target-unavailable`). Наличие строки в плане не является подтверждением. RTO/RPO не проверены.
2. **R_PERFORMANCE (not_run):** замеры не проводились.
3. **Целостность:** хеш пакета не вычислен.
4. **Документация:** старое руководство (1.4.2) содержит опасные советы и неверные лимиты.
